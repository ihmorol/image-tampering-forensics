# Literature collection

This folder contains the papers and citation records used for the manuscript.
The primary local copy is `papers/farid2009_jpeg_ghosts.pdf`. Several publisher
PDF endpoints reject automated downloads, so the remaining records preserve a
stable DOI and publisher link in `docs/literature-review.md` and
`writings/original/references.bib`.

The literature is used to select and compare candidate cues. It does not justify
claiming that any cue works on every image or that the final fusion is superior
before the held-out evaluation is complete.
