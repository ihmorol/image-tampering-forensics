# Literature collection

This folder contains the papers and citation records used for the manuscript.
Every PDF here was retrieved from an author homepage, an institutional host, or
a publisher open-access page. Papers whose publishers provide no openly
downloadable copy are recorded by DOI only and are never cited as though they
had been read in full.

Per-paper reading notes are in `notes/`. Each entry states whether the source
was read in full, read partially, or seen only as an abstract, and every number
quoted from a paper carries the section or table it came from. File hashes are recorded in
`datasets/README.md` and should be checked before reuse.
