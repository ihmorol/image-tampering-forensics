# Literature collection

This folder contains the papers and citation records used for the manuscript.
The local paper collection includes author-hosted copies of Farid (2009),
Popescu and Farid (2005), and Wen et al. (2016). The remaining records preserve
stable DOI and publisher links because their publishers do not provide an
openly downloadable copy from this environment. File hashes are recorded in
`datasets/README.md` and should be checked before reuse.

The literature is used to select and compare candidate cues. It does not justify
claiming that any cue works on every image or that the final fusion is superior
before the held-out evaluation is complete.
