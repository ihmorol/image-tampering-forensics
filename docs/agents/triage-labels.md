# Triage Labels

Use these labels for the five canonical triage roles:

| Role | Label | Meaning |
| --- | --- | --- |
| Needs evaluation | `needs-triage` | A maintainer must evaluate the issue. |
| Waiting for reporter | `needs-info` | More information is required. |
| Ready for an agent | `ready-for-agent` | The issue is fully specified for agent work. |
| Ready for a human | `ready-for-human` | Human implementation or judgment is required. |
| Will not fix | `wontfix` | The issue will not be actioned. |
